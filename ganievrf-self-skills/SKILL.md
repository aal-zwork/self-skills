# ganievrf-self-skills

## Языковая конвенция

- `AGENTS.md` (во всех трёх репозиториях — `ansible`, `secrets`, `skills`) —
  **на английском**.
- `README.md`, содержимое скиллов (`skills/ganievrf-self-*`) и `docs/*` —
  **на русском**.

## Структура скилла

Каждый `ganievrf-self-*` — папка с `SKILL.md`, фронтматтер:

```yaml
---
name: ganievrf-self-<name>
description: >-
  Одна-две фразы, что покрывает скилл и чем отличается от соседних
  (cross-ref на другие ganievrf-self-* через их имена).
---
```

## Когда создавать новый скилл

- Новая устойчивая область знаний об этой инфраструктуре, которая не
  вписывается в существующие четыре (`adm`, `secrets`, `ansible`) и не
  является самим хабом (`common`).
- При создании — сразу добавить его в дерево в `ganievrf-self-common`.

## Когда дополнять существующий

- Появилась находка (рабочая команда, ловушка, уточнённая процедура) в ходе
  реальной задачи — дополнить соответствующий скилл, не оставлять только в
  истории чата.
- Не раздувать скилл деталями конкретного issue — общие архитектурные факты
  остаются в скилле, детали одной задачи — в `docs/` этой задачи.
